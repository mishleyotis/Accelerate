# Artifact coverage census — DMA package corpus

Generated by `backend/scripts/artifact_coverage_census.py` on 2026-07-02 against `backend/tests/fixtures/dma_packages_batches` (113 package roots).

Status vocabulary:

- **CONSUMED** — a dedicated parser persists the artifact into domain tables (scores/evidence/recs/peers/sections/…).
- **KNOWLEDGE** — Part 12.6 unconsumed-artifact parser → `client_knowledge_sections` (+ `runs.uncertainty_bands`).
- **GENERIC** — no fingerprint matched; the generic section-miner persists capped `artifact_kind='generic'` sections AND records an `nlp.patterns` pattern_gap so the registry learns the shape.
- **EXCLUDED** — documented exclusion (narrative-deck placeholders, VIZ PNGs, duplicate xlsx twins ride the CONSUMED workbook path, scoring scratchpads are recomputable, search logs are optional provenance, evidence twins duplicate `evidence_index`).

Every MATERIAL artifact — whatever its status — is additionally persisted compressed into `raw_artifacts` (Part 12.2: zstd-9 for text-likes, verbatim for docx/xlsx/pdf, global sha256 dedup), so re-parse never re-downloads and provenance is byte-exact.
