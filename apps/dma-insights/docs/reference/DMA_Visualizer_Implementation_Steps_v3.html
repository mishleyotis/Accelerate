# DMA Visualizer — Claude Code Project Instructions

## Project overview
Internal Zennify web app that transforms completed Digital Maturity Assessments into an interactive intelligence workspace. Two phases: Phase 0 (Google Drive import) and Phase 1 (Claude Project API real-time streaming).

## Tech stack
- **Backend**: FastAPI (Python 3.11+) on Google Cloud Run
- **Frontend**: Next.js 14 (App Router) + TypeScript on Cloud Run
- **Database**: Cloud SQL PostgreSQL 15 with pgvector extension
- **Cache**: Upstash Redis (SSE fan-out + job queue)
- **Storage**: Google Cloud Storage (artifacts, PDFs)
- **AI**: Vertex AI Gemini 2.0 Flash (8 intelligence surfaces) + Gemini Pro (meeting_prep)
- **Auth**: Google OAuth 2.0 + JWT (httpOnly cookie), @zennify.com domain restriction
- **CI/CD**: GitHub Actions → Cloud Build → Cloud Run
- **Monitoring**: Cloud Monitoring + Cloud Trace + structured JSON logging

## Key conventions
- **BEM naming**: Block__Element--Modifier for CSS classes (e.g., `heatmap-cell__tooltip--active`)
- **File naming**: PascalCase for React components, snake_case for Python modules
- **API prefix**: All backend routes under /api/v1/
- **Environment**: .env.local for frontend, .env for backend — NEVER commit secrets
- **Maturity palette**: M1=#C25008, M2=#FE9732, M3=#FFD166, M4=#7BC47F, M5=#059669, No score=#E5E7EB
- **Zennify brand**: Primary teal #27BBAF, Dark #1C4A4D, Purple #735BA1, Font: DM Sans
- **Sub-cap ID format**: P{n}C{cat}.{l1}.{n}[.{sv}{n}] (e.g., P1C1.1.1, P2C1.4.IB1)

3CCG data reload strategy: When V7 capability mapping is updated (e.g., V7.1), the reload process is: (a) create new migration adding/modifying CCG columns if needed, (b) run etl/ccg_loader.py --version v7.1 which truncates and reloads CCG tables while preserving engagement data (subcap_scores, evidence), (c) verify FK integrity post-reload.
4Zero-downtime migrations: All production migrations must be backwards-compatible. Strategy: add new column (nullable) → deploy new code → backfill → add NOT NULL constraint. Never drop columns in the same deployment that removes the code using them.
