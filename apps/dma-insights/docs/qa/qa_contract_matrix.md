## §6 — Cache key matrix

**Frontend TanStack-Query keys** (from `queries.ts` `queryKey` lines):
- `["dashboard", scope]` — 30s staleTime
- `["entities", opts]` — 60s staleTime
- `["overview", id, run?]` — 5min staleTime; invalidated on `useRequestNewRun`
- `["heatmap", id, run?]` — 5min staleTime
- `["insights", id, run?]` — 5min staleTime
- `["platforms", id, run?, view?]` — 5min staleTime
- `["context", id, run?]` — 5min staleTime
- `["health", id, run?]` — 1min staleTime (faster freshness for ops)
- `["runs", id]` — 30s staleTime
- `["evidence", id, run?, subcap?]` — 5min staleTime
- `["alerts"]` — 30s staleTime
- `["focus", id]` — 5min staleTime
- `["fa-kpis", id, fa_id]` — 1min staleTime
- `["notif"]` — 15s staleTime; refetched on Pub/Sub SSE event
- `["annot", id, ic_id]` — 5min staleTime; invalidated on save

**Backend Redis keys** (from grep `rl:` + `cache:` patterns):
- `rl:{surface}:{user_id}:{ymd}` — rate-limit counters per RAG surface
- `cache:vertex:{fingerprint}` — Vertex response (mirror of `vertex_synthesis_cache`)
- `cache:learning_signals:{surface}` — 5min cache of chat_learning_signals for re-rank
- `sse:notif:{user_id}` — SSE channel keys

**Synthesis fingerprint** (from `synthesis_orchestrator.py`):
`input_fingerprint = SHA256(prompt_template_version + grounding_bundle_hash + catalogue_version + page_context_hash)`. Catalogue version is always in the fingerprint, so a catalogue bump auto-misses every row without explicit invalidation.
