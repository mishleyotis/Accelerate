## Root cause + remediation

The violations source from **the bot pipeline's writing**: the
assessment_report.docx prose (parsed into `document_sections.body`)
and the per-subcap rationales (parsed into `subcap_scores.rationale`)
are emitted by the DMA generator agents using neutral / technical
language. The Zennify product voice is a *consumer* of these — the
sanitization should land in the **rendering pipeline** (the
`synthesis_orchestrator` + `subcap_narrative_extractor`), not by
mutating the source-of-truth persisted blobs.

Three options for the remediation:

1. **(Recommended)** Add a Vertex post-processing pass in
   `synthesis_orchestrator` that rewrites rationale + section_body
   into Zennify voice before serving. Cached via the
   `vertex_synthesis_cache` UPSERT so we pay the rewrite once per
   fingerprint. Keeps the source narrative pristine for audit while
   the rendered surface speaks Zennify.
2. **(Faster but heavier)** Run a one-time
   `app/scripts/sanitize_language.py` that mutates the persisted
   blobs in place — losing source-of-truth provenance but instantly
   compliant.
3. **(Cheapest)** Add a rule-based regex substitution layer at the
   API boundary (`/entities/{id}/heatmap/subcap/{subcap_id}` etc.)
   that swaps the 6-rule-violating phrases inline before serving.
   Risk: clunky readings ("areas of focus" inserted where "weakness"
   was contextually correct).

Option 1 fits the existing synthesis_orchestrator + token-economics
contracts and is the cleanest long-term path. The audit harness
(this script) is the regression gate — re-running it after the
rewrite pass should show the violation count drop to near-zero on
served narratives.

## Important caveat

These violations are in **DB-persisted narratives** that flow from
the bot pipeline. They are not user-facing UI strings (buttons,
toasts, error messages) — those obey the brief by construction in
the React component library. The rendered DMAs surface this prose,
so customer-facing readers see the un-sanitized language until the
rewrite pass lands.
