# Craft

The difference between a payload that validates and one worth reading.

`1-reasoning` is the R-Layer: the only mechanism that catches a claim which is well-formed, correctly cited, grain-locked and wrong. `2-platform-story` covers the highest-defect surface in the corpus. `3-page-narrative` is why a page is not a container for surfaces. `4-card-anatomy` is where each field lands and how long it may be. `5-prompt-standard` is for writing a prompt where none exists.
