## Template Validation Rules

After selection, verify:
1. Template file exists and has exactly 22 slides
2. Slide 5 headline text contains expected sub-vertical keyword
3. **Slide 6 has exactly 40 shapes** (was 7 in older templates — if 7 or less, template is stale and uses the old 2-paragraph layout)
4. **Slide 10 has exactly 44 shapes** (was 11 in older templates — if <44, template is stale)
5. Slide 14 has ≥150 shapes (new heatmap design)
6. No `typeface="Arial"` in slide XML after `template_preparer.py` runs (DM Sans only; font normalization is part of the main flow, no separate flag needed)
7. Post-normalization: `grep "Higginbotham"` returns 0
8. Post-normalization: `grep "\[Customer name\]"` returns 0 on Slide 10 (new placeholder variant — see editing_contract §11 rule #18)
9. Slide 10 hardcoded scores (`2.6`, `2.9`) in Sh7 have been replaced by `slide10_editor.py` — verify via `placeholder_manifest.json` that no literal `2.6 (out of 5)` or `peer median of 2.9` remain

## GitHub Template Hosting (Optional)

If you prefer GitHub over Google Drive for auto-download:

### One-Time Setup
1. Create a private or public GitHub repo (e.g., `zennify/dma-templates`)
2. Download each Google Slides template as PPTX:
   - Open each link → File → Download → Microsoft PowerPoint (.pptx)
3. Upload to the repo under a `templates/` folder using these exact filenames:
   ```
   templates/cib_banking.pptx
   templates/commercial_lending.pptx
   templates/credit_unions.pptx
   templates/farm_credit.pptx
   templates/insurance_brokerages.pptx
   templates/insurance_carriers.pptx
   templates/retail_banking.pptx
   templates/wealth_asset_management.pptx
   templates/wealth_rias.pptx
   ```
4. Add `raw.githubusercontent.com` to Claude's network egress allowed domains:
   - Settings → Capabilities → Allow network egress → "Package managers and specific domains" → add `raw.githubusercontent.com`

### Download Command (used automatically by the skill)
```bash
wget -O /home/claude/working/template.pptx \
  "https://raw.githubusercontent.com/{OWNER}/{REPO}/main/templates/{sv_id}.pptx"
```

### Updating Templates
When templates change in Google Drive:
1. Re-download the updated PPTX from Google Slides
2. Push to the GitHub repo (replacing the old file)
3. The skill automatically picks up the new version on next run

**Note:** GitHub has a 100MB file limit per file. Each template is ~60MB, well within the limit. For repos with large binary files, consider GitHub LFS if the repo grows significantly.
