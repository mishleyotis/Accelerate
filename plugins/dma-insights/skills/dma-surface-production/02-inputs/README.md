# Inputs

Where the material comes from, and what is authoritative for what.

Read `1-package` when orienting in an assessment folder. Read `5-corpus-map` before producing any surface — it maps each surface's package sources with fallbacks per structure generation, the storyline inputs, and the measured enrichment precedence (P0 package-blind facets first), plus the resilience ladder every lookup walks (resolve → corpus → web → honest absence). Read `2-clay-enrichment` before running enrichment — it carries the budget and the tier each returned data point registers at, and getting the tier wrong caps capabilities. Read `3-mcp-tools` for any exchange you would otherwise guess at. Read `4-vetting` for what each mechanical finding does downstream.
