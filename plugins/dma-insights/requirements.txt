# Third-party Python the bundled skill scripts import.
#
# Declared here rather than fixed in place: the scripts are correct, they
# simply have dependencies, and a plugin that pretends otherwise reports a
# green audit on a machine where eleven deck editors cannot start. Install
# with `dma-deps install`; see what is missing and what it blocks with
# `dma-deps check`.
#
# Pins follow each skill's own scripts/requirements.txt where one exists.
# Ranges are used where the skill pinned nothing, so an install here does not
# silently downgrade an environment that already works.
#
# The scientific stack is ranged rather than pinned: the skills' exact pins
# (pandas 2.0.3, numpy 1.24.3, pyarrow 12.0.0, matplotlib 3.7.2) publish no
# cp312/cp313 wheels, so on 3.12/3.13 they resolve to sdists and a source
# build. The lower bounds are those pins — the versions the skills were
# validated on under 3.11. Per-interpreter resolution is pinned by the
# constraints files alongside this one: constraints-py311.txt is the measured
# working set, constraints-py312.txt / constraints-py313.txt pin the oldest
# versions that publish cp312/cp313 wheels. dma-deps selects the file by
# interpreter.
